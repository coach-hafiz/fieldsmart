# FieldSmart — Striking & Fielding Lab

Public-access, no-login teaching web app for striking and fielding and softball tactical decision-making.

## Modes

- Fielding simulation — 5 fielders, 2 or 3 bases
- Fielding gameplay — 5 fielders, 2 or 3 bases
- Softball fielding simulation — 10 fielders, 4 bases
- Softball fielding gameplay — 10 fielders, 4 bases

Drag fielders and the ball, choose a hit type, and demonstrate a response or analyse the fielders' final defensive positions. Feedback is heuristic teaching guidance, not a real-time physics or rules engine. The field scales to fit the visible screen area; controls may scroll on a phone.

## Run locally

```bash
npm install
npm run dev
```

## Vercel

Import this repository at https://vercel.com/new . Framework: Vite. Build command: `npm run build`. Output directory: `dist`. Do not enable deployment protection if students need anonymous access.

## Content access

Do not upload restricted MOE syllabus source documents into a publicly accessible GitHub repo or deploy them as static assets. Content in this app is original teaching-oriented paraphrase.
